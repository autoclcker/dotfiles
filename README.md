# dotfiles
Typical setup for a desktop environment

### Prerequisites

- **Packages:** git, make, sudo
- **Hardware:** x86 **or** x86_64, NVIDIA (optional)

> [!IMPORTANT]
> To successfully install all github-related utilities, you need to specify the environment variable **GITHUB_TOKEN** before installation, e.g.:
>
> ```
> export GITHUB_TOKEN=%%YOUR_GITHUB_TOKEN%%
> ```

> [!TIP]
> ```
> make
> ```
